# 🍗 The Chicken Co.

A premium, front-end web application for a fictional fast-food chain. Built with a focus on modern, rich aesthetics and fluid user experience.

## ✨ Features

- **Premium Design System**: Dark theme accented with vibrant Gold (`#FFB800`) and Fire (`#FF4500`).
- **Interactive UI**: Custom cursors, micro-animations on hover, scroll-linked progress bars, and glowing effects that bring the application to life.
- **Dynamic Menu Filtering**: Easily sort through Wings, Burgers, Grilled items, and Combos with smooth fade animations.
- **Fully Responsive**: Flawless experience from desktop down to mobile.
- **Functional Prototypes**:
  - **Cart & Checkout**: Stateful cart functionality saving locally, with auto-fill enabled during checkout.
  - **Account System**: Mock login, editable profile details, order tracking with progress steppers, and a coupons/offers section.

## 🚀 Pages Include

- `index.html` — Landing page with hero banner, bestsellers, story, and newsletter.
- `menu.html` — Full menu with category filtering and portion selection.
- `cart.html` — Shopping cart with item management and real-time total calculation.
- `checkout.html` — 3-step checkout process (Contact, Delivery, Payment) featuring profile auto-fill.
- `confirmation.html` — Order success page with timeline and animated effects.
- `login.html` — Sleek, split-layout sign-in page with mock social auth.
- `profile.html` — Account management to update personal and delivery details.
- `orders.html` — Tracking for active and past orders, complete with a visual progress stepper.
- `offers.html` — Coupon dashboard with quick "copy to clipboard" functionality.

## 🛠️ Tech Stack

- HTML5
- CSS3 (Vanilla, heavily relying on CSS Grid, Flexbox, Variables, and Keyframes)
- JavaScript (Vanilla, ES6+ for DOM manipulation and LocalStorage)

## 💻 Getting Started

This is a static, vanilla web project. No build tools or package managers are required.

1. Clone or download the repository.
2. Open `index.html` in your favorite modern browser.
3. Enjoy the fried chicken experience!
